# Blog Pet Project

This is repository of pet blog project.

## Using

Libs and technics:

- TS
- React (Router DOM)
- Redux Toolkit
- TailwindCSS
- Jest Testing
- CI/CD (auto deploy to VPS)
- Axios
- React Forms
- Linters
- Git

## Available Scripts

In the project directory, you can run:

### `npm start`

### `npm test`
